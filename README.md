## Description

Dépôt de démarrage TypeScript du framework [Nest](https://github.com/nestjs/nest).

## Installation

```bash
$ npm install
```

## Lancement de l'application

```bash
# développement
$ npm run start

# mode surveillance
$ npm run start:dev

# mode production
$ npm run start:prod
```

## Tests

```bash
# tests unitaires
$ npm run test

# tests de bout en bout
$ npm run test:e2e

# couverture des tests
$ npm run test:cov
```
